# 世界動物尋蹤 · Emerald Safari

[在 iPad 開啟遊戲](https://cfsthk.github.io/school-safari-field-test/?rom=114)

這個版本用 mGBA 在瀏覽器直接運行 Emerald Safari 1.14。遊戲保留卡帶的 240 × 160 畫面、跟隨角色捲動的鏡頭、地圖、對話、背包、圖鑑和 Safari 回合。另一圖層在原生視野內顯示同學及班別姓名。

## 開始遊戲

在 GitHub Pages 首次選取本機的 **Emerald-Safari.gba**，或選取未經修改的美歐版 **Pokémon Emerald**。網站會在裝置上核對版本，並在需要時把更新套用到副本。日後用相同瀏覽器開啟即可繼續。清除網站資料後需要重新匯入。校內預載版本可直接進入遊戲。

用十字鍵移動、A 交談或確認、B 返回。START 開啟原版遊戲選單，SELECT 在野外開啟圖鑑。遊玩、儲存和邀請同學均可透過觸控操作。

## 校園連線

點同學圖示，選「同學連線」和「開設房間」。將邀請連結交給另一部裝置，房主保持遊戲頁面開啟。每位玩家可以設定班別和姓名。玩家在自己存檔的位置出發，進入同一地圖並走近，才會互相看見。打開背包或進入相遇時，每個人繼續自己的回合。單機模式在 101 號道路有 29 位示範同學，可在連線選單隱藏。

GitHub Pages 入口公開，房間透過邀請連結加入。此試玩版未接駁學校帳戶驗證。瀏覽器把班別、姓名和地圖狀態加密後經 EMQX 測試服務轉發。遊戲檔和進度保存在玩家裝置。

## 儲存與轉移

遊戲內按 **START → 儲存**，等候遊戲確認完成。瀏覽器會保存卡帶進度。點同學圖示的「存檔管理」可匯入或匯出 128 KiB 的 .sav，亦可匯入附帶 RTC 尾端的 mGBA 存檔。

## 執行及檢查

在本目錄使用 `python3 -m http.server 8000`，用瀏覽器開啟 `http://localhost:8000/`。跨裝置使用 HTTPS。單元測試使用 `npm test`，可選擇設定 `SAFARI_ORIGINAL_ROM` 驗證補丁能逐位元組重建正式版。學校內部部署可在私有網站的 school-config.js 指定自己持有的同源卡帶路徑。
