# 世界動物尋蹤 · Emerald Safari

[在 iPad 開啟遊戲](https://cfsthk.github.io/school-safari-field-test/?screen=1)

這個版本用 mGBA 在瀏覽器直接運行 Emerald Safari 1.14。遊戲保留卡帶的 240 × 160 畫面、跟隨角色捲動的鏡頭、地圖、對話、背包、圖鑑和 Safari 回合。另一圖層在原生視野內顯示同學及班別姓名。

## 開始遊戲

在 GitHub Pages 首次選取本機的 **Emerald-Safari.gba**，或選取未經修改的美歐版 **Pokémon Emerald**。網站會在裝置上核對版本，並在需要時把更新套用到副本。日後用相同瀏覽器開啟即可繼續。清除網站資料後需要重新匯入。校內預載版本可直接進入遊戲。

把 iPad 橫放，遊戲會填滿網頁。鎖定直向時，遊戲會向右旋轉 90°，仍可橫放遊玩。畫面左下的十字鍵用來移動，右下的 A 用來交談或確認，B 用來返回。自由探索時，點 A、B 旁的「選單」即可開啟綠寶石選單，查看圖鑑、背包或地圖。對話和相遇期間，按鍵會移到文字框上方。

## 校園連線

點「選單」後，選「同學連線與檔案」→「同學連線」→「開設房間」。將邀請連結交給另一部裝置，房主保持遊戲頁面開啟。每位玩家可以設定班別和姓名。玩家進入同一地圖並走近，便會互相看見。打開背包或進入相遇時，每個人繼續自己的回合。單機模式在 101 號道路有 29 位示範同學，可在連線選單隱藏。

GitHub Pages 入口公開，房間透過邀請連結加入。此試玩版未接駁學校帳戶驗證。瀏覽器把班別、姓名和地圖狀態加密後經 EMQX 測試服務轉發。遊戲檔和進度保存在玩家裝置。

## 儲存與轉移

進度會自動保存在這部裝置，包括體力、背包、金幣和已目擊但尚未上報的資料。首次遊玩在未白鎮研究所由博士接待。其後重新開啟遊戲或匯入有效存檔時，會從離上次位置最近、可到達的醫護站櫃檯繼續。抵達時保留原有體力，可跟護士交談補血。短暫切換分頁後返回，會在原場景繼續。

點「選單」→「同學連線與檔案」→「存檔管理」，可匯入或匯出 128 KiB 的 .sav，亦可匯入附帶 RTC 尾端的 mGBA 存檔。換裝置前可以匯出考察進度。

## 園區時間

一個完整日夜循環為現實的 90 分鐘，依次為早上 22 分鐘、下午 28 分鐘、黃昏 15 分鐘、夜晚 25 分鐘。戶外地圖和同學角色的色調隨時間漸變。室內、洞穴和遊戲文字保留原有配色。網站使用同一個校園時鐘決定光暗和動物的活動時段；連線時向網站校時，未能取得時間時先依裝置時間運行。

## 執行及檢查

在本目錄使用 `python3 -m http.server 8000`，用瀏覽器開啟 `http://localhost:8000/`。跨裝置使用 HTTPS。單元測試使用 `npm test`，可選擇設定 `SAFARI_ORIGINAL_ROM` 驗證補丁能逐位元組重建正式版。學校內部部署可在私有網站的 school-config.js 指定自己持有的同源卡帶路徑。
