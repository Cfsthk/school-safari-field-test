# 世界動物尋蹤 · 校園連線試玩

用 iPad 的 Safari 開啟 [考察地圖](https://cfsthk.github.io/school-safari-field-test/)。按住十字鍵逐格行走，A 交談或確認，B 返回。在電腦上也可用方向鍵、Z 和 X。

## 兩部裝置一起試玩

1. 第一部裝置打開右上選單，選「同學連線」及「開設房間」。
2. 選「分享房間連結」，把同一條連結交給同學在另一部裝置開啟。房主的分頁須保持開啟。
3. 兩位學生可以保留獲派的虛構姓名，也可以在房間內選「設定班別和姓名」。走動時會看到同學頭上的班別和姓名。各自在高草叢展開獨立考察。
4. 直接開啟遊戲首頁可體驗 30 位模擬學生同區的情境。連線房間只顯示實際加入的玩家。

## 試玩範圍

沿 101 號道路南行到未白鎮、北行到古辰鎮。進入新區域時地名會短暫出現。面向護林員或路牌按 A 可查詢，在未白鎮研究所門外找博士可上報、領取金幣和補給。試玩收錄四種動物及每種五段考察筆記，個人進度保存在本機瀏覽器。

GitHub Pages 提供公開試玩入口。房間依邀請連結加入，這版沒有學校帳戶驗證。連線試玩使用 EMQX 的公開測試訊息服務。傳送前，瀏覽器會使用房間連結內的秘密加密班別、姓名和地圖狀態。房主持有同區名單，其他參加者透過房間接收更新。個人的動物考察筆記和金幣保存在本機。任何持有完整邀請連結的人均可加入房間。

## 本機執行

在這個資料夾執行 `python3 -m http.server 8000`，以瀏覽器開啟 `http://localhost:8000/`。跨裝置試玩請使用上方的 HTTPS 網址。遊戲採用原創網頁圖像，地形和操作參照 GBA 版本。通訊函式庫 Eclipse Paho 的授權見 [vendor/paho-LICENSE.txt](vendor/paho-LICENSE.txt)。
